# soltech_master_app

Unified Soltech Flutter app for Passenger, Driver, and Fleet Owner roles.

## Notes

- Package name: `soltech_master_app`
- Display name: `Soltech`
- The app uses the existing Firebase project, Realtime Database, Firebase Auth, and Google Maps setup.
- Passenger and driver flows were migrated from `apps/passenger_app` and `apps/driver_app`; those apps remain reference targets during migration.
- Run app-level commands from this directory, for example `flutter pub get`, `flutter analyze --no-pub`, and `flutter run`.
