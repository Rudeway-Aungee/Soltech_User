# Dart Code Comments Added

This `lib` folder has comments inserted directly inside the `.dart` source files.

Look for comments starting with:

```dart
// CODE COMMENTS
// BEGINNER NOTES
```

The most heavily commented files are:

- `features/gateway/welcome_role_page.dart` — unified entry login/register flow.
- `features/passenger/passenger_home_page.dart` — passenger booking and ride tracking flow.
- `features/passenger/passenger_destination_page.dart` — destination search, multiple stops, and map pin flow.
- `features/driver/driver_home_page.dart` — driver online, accept, arrive, start, complete trip flow.
- `features/fleet_control/fleet_control_home_page.dart` — fleet dashboard, vehicles, trips, ledger.
- `features/fleet_control/fleet_control_driver_management_page.dart` — driver creation by Fleet Control.
- `core/session/app_session.dart` — role detection and routing.

These comments do not change app behavior; they are only for review and understanding.
